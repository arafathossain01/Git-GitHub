1. git init      -->  Used to create a new Git repository and bring an existing project under version control.
2. git status    -->  Show the changes of local file or folder, such as: unmerged(U), modified(M), added(A), renamed(R), untracked(??),
                      deleted(D), copied(C), ignored(!).
3. gil clone URL -->  Use to bring a remote repository (cloud) to local machine.
4. git add       -->  Take file changes and move it for staging. 
                     1.git add . ,it's move those file in stage that are create or modify or deleted file (V2.0+). it work in current directory.
                     2.git add --all / git add -A ,it's move all file in stage. it work for all directory.
                     3.git add file_name ,it move only fine_name into staging.
5. git reset     -->  Use for current staging reset.
6. git restore --staged file_name --> remove from stage deleted file or folder
7. git restore file_name --> restire the deleted file or folder in local machine.
